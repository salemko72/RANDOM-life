# LifeShuffler brand

Approved 19 October 2026: serif wordmark, Life in light rose-taupe and Shuffler
in softer dark brown. The small five-sector wheel replaces the dot on the i,
with the final intermediate vertical spacing. No large emblem above the name.

The optimized transparent wordmark is
`apps/client/src/web/assets/brand/lifeshuffler-wordmark.webp` (1400 × 251).
`BrandLogo.tsx` presents it accessibly as LifeShuffler. It appears on splash,
home header and onboarding. The tagline remains Manje dilema, više života /
Decide Less. Live More. Shared-page metadata and legal pages use the new name.

Native launcher artwork uses the approved wheel alone on dusty rose. Adaptive
foreground is transparent with safe margins; background and monochrome assets
are included. Favicon uses the same icon. Expo display name is LifeShuffler.

Package ID, Expo project/slug, public hostname, item URLs, storage keys and bridge
protocols keep their existing identities so updates preserve users and content.
The existing 0.20.0 (3) APK/AAB predates this rebrand. The next Android build must
increment versionCode and regenerate its installed HTML before upload.
